# 🎲 WordPlay — игра для изучения словацкого языка

Слово ↔ картинка по плиткам. Три режима, 315 слов, 21 тема, озвучка на словацком, XP и серии правильных ответов.

**Живая демонстрация (GitHub Pages):** https://ВАШ_ЛОГИН.github.io/имя-репозитория/wordplay/

## Как запустить локально

Просто откройте `wordplay/index.html` в браузере — никакой сборки не нужно.

Или через локальный сервер:

```bash
cd wordplay
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Режимы игры

| Режим | Что делает игрок |
|---|---|
| 🖼️ **Obrázok → slovo** | Показана картинка (эмодзи), нужно выбрать правильное словацкое слово из 6 плиток |
| 🔤 **Slovo → obrázok** | Показано словацкое слово + перевод, нужно выбрать нужную картинку |
| 🧩 **Poskladaj slovo** | Собери слово по буквам из плиток-букв (словацкая раскладка: ä, ô, ŕ, ľ, ž…) |

## Возможности

- 📚 **315 слов** с переводом на русский и эмодзи-картинками
- 🗂️ **21 тема**: животные, еда, фрукты/овощи, цвета, тело, одежда, дом, природа, транспорт, школа, дни недели, город, семья, спорт, глаголы, числа и др.
- 🎚️ **3 уровня сложности**: A1 / A2–B1 / B1+
- ⭐ XP, серия правильных ответов 🔥, прогресс раунда, медаль по итогам
- 🔊 Озвучка слов на словацком (speechSynthesis sk-SK) + звуковые эффекты (WebAudio)
- ➕ **Своя колода** — добавляйте свои слова (слово + перевод + эмодзи) и играйте только ими; всё сохраняется в localStorage
- 📱 Адаптивная вёрстка (телефон/десктоп)

## Структура проекта

```
wordplay/
├── index.html   # разметка и экраны игры
├── style.css    # оформление

```

Чистый Vanilla JS — без фреймворков, зависимостей и сборки.

## Публикация на GitHub Pages

1. Откройте репозиторий → **Settings** → **Pages**
2. В разделе **Build and deployment** → Source: **Deploy from a branch**
3. Branch: `main`, папка: `/wordplay`, нажмите **Save**
4. Через пару минут игра будет доступна по адресу вида
   `https://ваш-логин.github.io/имя-репозитория/`
